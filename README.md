# Python Problem-Solving Toolkit 🐍

A collection of beginner-friendly Python projects built while learning programming and problem-solving as a BTech Information Technology student.

## 🚀 Projects

### 1. Basic Python Calculator

A command-line calculator that performs basic arithmetic operations.

**Features**
- Addition (+)
- Subtraction (-)
- Multiplication (*)
- Division (/)
- Handles division by zero
- Accepts decimal numbers

## 🛠️ Technologies Used

- Python 3
- Visual Studio Code
- GitHub

## ▶️ How to Run

1. Install Python 3.
2. Download or clone this repository.
3. Open a terminal in the project folder.
4. Run:

   `python calculator.py`

On Windows, you can also try `py calculator.py`.
